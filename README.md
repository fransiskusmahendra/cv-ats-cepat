# 📄 CV Kilat ATS — Generator CV ATS-Friendly Gratis & 100% Lolos Screening

Aplikasi web modern, instan, dan ramah smartphone untuk membuat Curriculum Vitae (CV) standar **Applicant Tracking System (ATS)** resmi HRD di Indonesia.

## ✨ Fitur Utama
- **100% Client-Side:** Cepat, aman, data tidak pernah disimpan di server (privasi terjaga).
- **Format 1 Kolom Bersih:** Standar resmi ATS agar lolos robot seleksi otomatis (SSCASN, Jobstreet, Workday).
- **Template Ringkasan Instan:** Tersedia pilihan kalimat profesional untuk Fresh Graduate, Staf Admin, IT Support, dan Kasir/Sales.
- **Unduh PDF A4 Presisi:** Tanpa watermark, tanpa registrasi berbelit, dan tanpa jebakan kartu kredit.
- **Aksen Warna Formal:** Pilihan warna profesional (Navy Blue, Slate, Emerald Green, Monochrome).
- **Live Real-Time Preview:** Tampilan hasil langsung terupdate di samping saat mengisi formulir.
- **Salin Teks Mentah:** 1 klik untuk menyalin seluruh isi CV agar mudah ditempel di form portal kerja.

## 🚀 Deployment
Web app ini siap di-deploy secara instan ke **Vercel** atau **Cloudflare Pages** dengan biaya hosting Rp 0 selamanya.
